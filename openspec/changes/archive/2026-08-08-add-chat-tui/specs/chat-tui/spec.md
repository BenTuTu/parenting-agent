# Delta: chat-tui

## ADDED Requirements

### Requirement: 常驻交互式对话界面

系统 SHALL 提供基于 Ink 的终端对话界面（`pnpm chat`，支持 `--session <id>` 参数，默认 `cli`）：进程常驻，用户可连续输入问题，Agent 回答完成后输入框重新可用；Agent 运行期间输入框 SHALL 禁用。

#### Scenario: 连续多轮提问

- **WHEN** 用户在 TUI 中先后提交两个问题
- **THEN** 两轮回答在同一进程内完成，第二轮无需重新加载历史或 wiki
- **AND** 第二轮回答能利用第一轮的上下文（如已提供的月龄）

### Requirement: 历史加载与持久化

TUI 启动时 SHALL 从会话存储加载该会话历史并将其中的用户/助手消息渲染为消息列表（工具调用往返不展示但完整保留于运行输入）；每轮回答完成后 SHALL 增量保存历史。

#### Scenario: 重开 TUI 恢复对话

- **WHEN** 用户退出后以相同 `--session` 重新启动 TUI
- **THEN** 之前的对话消息重新显示，追问可正确利用历史上下文

### Requirement: 流式渲染与工具状态可视化

Agent 回答 SHALL 以流式逐字渲染；Agent 调用工具期间 SHALL 显示状态行（加载动画 + 当前工具名），回答完成后状态行消失、消息转入静态区域（保留终端滚动缓冲，不因后续重绘闪烁）。

#### Scenario: 带工具调用的一轮回答

- **WHEN** 用户提问触发 `search_wiki` 与 `read_wiki_page` 调用
- **THEN** 状态行依次显示对应工具名
- **AND** 回答文本逐字出现，完成后固化为历史消息

### Requirement: 会话命令

TUI SHALL 支持输入命令：`/exit` 退出进程（恢复终端状态）；`/clear` 清除当前会话的持久化历史并清空界面消息列表。

#### Scenario: 清除会话

- **WHEN** 用户输入 `/clear`
- **THEN** 会话存储中该会话被删除，界面消息列表清空
- **AND** 后续提问以空历史开始

### Requirement: 运行环境约束

TUI SHALL 要求 TTY 环境（raw mode）；非 TTY 环境下 SHALL 输出明确错误提示并退出，脚本化场景由既有一次性 CLI 承担。

#### Scenario: 非 TTY 启动

- **WHEN** 在管道或无 TTY 环境启动 TUI
- **THEN** 输出提示（建议改用 `pnpm cli`）并以非零退出码退出，不残留坏终端状态

### Requirement: 上下文占用指示

TUI SHALL 在输入框下方常驻显示上下文占用进度条与百分比（当前 tokens / 上下文窗口上限，上限可经 `CONTEXT_WINDOW` 环境变量配置，默认 1000000）：启动时按历史内容启发式估算，每轮对话完成后 SHALL 更新为模型返回的真实 token 用量；占用超过 60% 与 85% 时进度条颜色依次变为警示色；`/clear` 后归零。

#### Scenario: 真实用量更新

- **WHEN** 一轮对话完成且模型响应携带 usage
- **THEN** 进度条按最后一次请求的总 tokens 更新百分比

#### Scenario: 清空归零

- **WHEN** 用户执行 `/clear`
- **THEN** 上下文占用显示归零

### Requirement: 红旗回复特殊样式

TUI SHALL 识别以 `⚠️【红旗警示】` 开头的助手回复（含流式渲染中的增量），以红色边框容器渲染并显示警示标题（"红旗警示 · 建议尽快就医"），正文中剥离原始标记；历史回放中的红旗回复 SHALL 同样以警示样式呈现。

#### Scenario: 红旗回复渲染

- **WHEN** Agent 返回以红旗标记开头的回复
- **THEN** 该消息以红色边框与警示标题渲染，流式过程即呈现警示样式

#### Scenario: 普通回复不受影响

- **WHEN** Agent 返回不含红旗标记的常规回复
- **THEN** 以常规助手消息样式渲染

### Requirement: Markdown 渲染

TUI SHALL 对助手回复做行级 Markdown 渲染（含流式增量与历史回放）：`#`-`###` 标题以醒目样式显示（"何时就医"标题用警示色）、`- `/`1. ` 列表以圆点/序号呈现、`**粗体**` 以终端粗体呈现且原始标记不显示；流式期间已完成行的渲染结果 SHALL 保持稳定（不闪烁），未闭合的粗体标记按持续到行尾处理。

#### Scenario: 流式期间渲染

- **WHEN** 回答正在流式输出且已出现完整的标题行与未完成的正文行
- **THEN** 标题行以标题样式稳定显示，未完成行随增量逐帧更新，不影响已完成行

#### Scenario: 原始标记不外泄

- **WHEN** 助手回复包含 `##`、`- `、`**` 等标记
- **THEN** 渲染结果不出现这些原始字符
