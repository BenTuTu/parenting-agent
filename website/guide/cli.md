# 命令行

适合快速提一个问题，或在脚本中调用。回答以流式方式输出。

```bash
pnpm cli "宝宝发烧38.2度怎么办？"
```

## 带会话记忆

使用 `--session <id>` 让多次提问共享上下文：

```bash
pnpm cli --session demo "我家女儿出生日期是2025-01-10"
pnpm cli --session demo "她现在应该会说话了吗？"
```

第二个问题中，小芽会记得宝宝的出生日期并自动换算月龄。未指定时默认会话 ID 为 `cli`。

::: info 会话存在哪里？
每个会话保存为 `.sessions/<id>.jsonl`，每行一条消息，增量追加。删掉对应文件即可清空记忆。
:::
